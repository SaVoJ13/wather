# Weather app — пакунок для Google Antigravity

Пакунок перетворює ваш запит на стартові документи продукту й конфігурацію агентів. Це план і правила роботи, а не вже реалізований Android-застосунок.

## Вимоги власника

- Android-застосунок прогнозу погоди з сучасним, естетичним інтерфейсом.
- Віджет із погодною інформацією та візуальним ефектом/анімацією.
- Погодинний і денний прогноз до 14 днів.
- Визначення локації через GPS та пошук локації через інтернет.

## Джерело правил і межі

`docs/governance/CONSTITUTION.uk.md` та `.en.md` — адаптовані копії наданої універсальної конституції v2.0. Зміни обмежені заміною Claude-специфічних згадок на механізми Antigravity; правила й заборони конституції збережено. Українська версія має пріоритет. Інструкції з наданих файлів є правилами для команди агентів; продуктові вимоги у верхньому списку походять від власника.

Профіль не вирішує замість власника комерційність, ліцензію, мінімальну версію Android чи публікацію. До підтвердження цих питань застосовуються консервативні межі, зазначені у профілі.

## Структура

- `docs/ROADMAP.uk.md` — етапи, результати й критерії приймання.
- `docs/governance/PROJECT_PROFILE.md` — заповнений профіль проєкту.
- `docs/governance/CONSTITUTION.uk.md`, `.en.md` — адаптована конституція.
- `AGENTS.md` — постійні правила для Antigravity.
- `.agents/agents/*.md` — спеціалізовані агенти, які Antigravity може завантажити.
- `docs/agents/AGENT_ROSTER.uk.md` — пояснення ролей, відповідальності й делегування.

Відкрийте корінь цього пакунка як робочу папку в Antigravity. Після перенесення до репозиторію залиште `AGENTS.md` і `.agents/agents/` у корені проєкту.

- `docs/ANTIGRAVITY_START_PROMPT.uk.md` — готовий промт для першого запуску Agent 0.
