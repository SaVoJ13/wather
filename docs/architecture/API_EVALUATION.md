## 1. Мета аналізу

Забезпечити повноцінне функціонування застосунку **«Weather — Smart Forecast»** з:
- 14-денним щоденним прогнозом;
- 24–48 годинним погодинним прогнозом;
- геокодуванням міст та сіл (пошук + визначення поточної локації);
- легальною комерційною моделлю (застосунок із рекламою, Ad-supported);
- мінімізацією API-витрат та захистом від блокування за квотами.

## 3. Детальний аналіз Open-Meteo (Поточний провайдер)

### Переваги:
1. **Висока точність у Європі та світі:** агрегує дані провідних національних метеорологічних служб (ECMWF IFS 9km, DWD ICON 2km/7km, NOAA GFS).
2. **Повна відповідність вимогам MVP:** 16 днів щоденного прогнозу, 16 днів погодинних даних (температура, вологість, точка роси, тиск, швидкість/пориви вітру, УФ-індекс, ймовірність опадів).
3. **Стандарт WMO:** прозорі числові коди погоди WMO 0–99, які легко мапляться на іконки та локалізовані описи.
4. **Архітектурна ізоляція:** адаптер `OpenMeteoHttpClient` уже реалізований через контракт `WeatherRepository`, тому бізнес-логіка та UI не залежать від конкретного HTTP-ендпоінту.

### Ліцензійні обмеження (Критично для Власника):
- **Умови Open-Meteo Terms:** Безкоштовний API надається під ліцензією CC BY 4.0 з умовою некомерційного використання. Розміщення реклами в додатку (Google AdMob) юридично кваліфікується як комерційне використання.
- **Рішення:** На фазі тестування та внутрішньої розробки використовується некомерційний режим Open-Meteo та `MockWeatherRepository`. Перед офіційною публікацією в Google Play Власник повинен обрати один із двох шляхів:
  - **Шлях 1:** Оформити підписку Open-Meteo Commercial (€29/міс).
  - **Шлях 2:** Переключити адаптер на комерційний план WeatherAPI.com ($15/міс).

## 5. Стратегія економії трафіку та батареї (Caching Strategy)

Щоб уникнути зайвих витрат API та зберегти заряд акумулятора:
1. **Дисковий кеш `WeatherLocalCache`:**
   - Кешує повний прогноз на 14 днів та 24 години для активного міста у SharedPreferences / Room.
   - Термін валідності кешу (TTL): **30 хвилин**. Повторний запуск додатку в межах 30 хв показує дані з диску миттєво (0 мс мережі).
2. **Smart Refresh у віджеті:**
   - Оновлення віджета за розкладом 1 раз на 10–15 хвилин через `AlarmManager.setAndAllowWhileIdle`.
   - Якщо телефон у режимі сну (Doze mode) або немає мережі — показуються закешовані дані з точним штампом часу оновлення.
3. **Обмеження фонових запитів:**
   - Повна відсутність фонового GPS-трекінгу (`ACCESS_BACKGROUND_LOCATION` суворо заборонено). Координати запитуються лише тоді, коли користувач відкрив застосунок і натиснув «Моє місцезнаходження».

## 6. Висновки та фінальне рішення Власника

1. **Рішення Власника (2026-11-22, ADR-009):** Затверджено **Варіант №3 — Розумну комерційну модель AdMob + WeatherAPI (0 грн витрат, 100% чистий прибуток)**.
2. **Провайдер комерційного релізу:** Сервіс **WeatherAPI.com** із безкоштовним планом до 1,000,000 викликів на місяць. Ліцензія сервісу офіційно дозволяє комерційну монетизацію через AdMob без жодних платежів, за умови наявності атрибуції («Weather data by WeatherAPI.com»).
3. **Провайдер етапу розробки та закритого тестування:** Продовжуємо роботу на безкоштовному Open-Meteo та `MockWeatherRepository`.
4. **Фінансові витрати проекту на API:** **0 грн / 0 $ (на постійній основі)**. Увесь дохід від реклами Google AdMob залишається чистим прибутком Власника.
