## 1. Огляд структури екранів та навігації

Відповідно до затверджених специфікацій Phase 1 та рішень Власника ([ADR-010](file:///C:/Users/cocro/Wather/docs/governance/DECISIONS.md), [ADR-011](file:///C:/Users/cocro/Wather/docs/governance/DECISIONS.md)):
1. **Нижня панель навігації (`NavigationBar` Material 3):** Суворо 3 вкладки:
   - **Вкладка 1: «Зараз» (`NowScreen`)** — Поточна погода, Hero з великою температурою, 24-годинна стрічка від поточної години, 2x2 сітка метрик, схід/захід сонця на Canvas, плашка атрибуції постачальника.
   - **Вкладка 2: «Прогноз» (`ForecastScreen`)** — Єдиний вертикальний скрол: зверху макро-тренд (графік температур на 14–16 днів), діаграма опадів, а під ними — детальний список днів із діапазонними Range Bars та відкриттям деталей дня через Bottom Sheet.
   - **Вкладка 3: «Місця» (`LocationsScreen`)** — Список збережених міст (до 10 міст) із поточною температурою та станом, поле пошуку з автодоповненням (debounce 400 мс, офлайн-база), кнопка додавання/видалення. Повний нуль псевдорадару.
2. **Окремий екран налаштувань (`SettingsScreen`):** Доступний через тач-іконку шестерні [⚙️] у верхній панелі `WeatherTopBar` на кожній із трьох вкладок. Містить одиниці виміру (°C/°F, км/год / м/с, гПа / мм рт. ст.), селектор мов (8 мовних пакетів), правові дані ліцензій та політику конфіденційності.
3. **Рекламний контейнер (`Anchored Adaptive Banner`):** Розміщується виключно в додатку безпосередньо над `NavigationBar` із резервуванням висоти (50–90dp) для **Zero CLS**. Суворо 0% реклами у домашньому віджеті Glance.

## 2. Матриця 11 UI-станів для основних розділів (UI State Matrix)

| № | Стан (UI State) | Що бачить користувач на екрані | Доступні дії користувача | Повідомлення для TalkBack (Accessibility Semantics) |
|---|---|---|---|---|
| **1** | **Loading (Первинне завантаження)** | М'який Shimmer-скелетон форми Hero-картки та карток метрик. Плавна пульсація без різких спалахів. | Навігація між вкладками, відкриття налаштувань. | *«Завантаження погодних даних для [Назва міста]... Будь ласка, зачекайте.»* |
| **2** | **Success (Успішне оновлення)** | Повні метеодані, живий градієнт неба (день/ніч/опади), актуальні значення, статус «Оновлено щойно». | Скрол, тап на день для деталей, зміна локації, pull-to-refresh. | *«Погода у [Місто]: [Стан], [Температура] градусів. Відчувається як [Температура]. Оновлено щойно.»* |
| **3** | **Refreshing (Pull-to-Refresh)** | Поточний екран залишається видимим; зверху з'являється круглий індикатор `PullRefreshIndicator`. | Скасування свайпом, очікування відповіді. | *«Оновлення прогнозу погоди...»* |
| **4** | **Empty (Порожній стан пошуку/міст)** | Ілюстрація контуру карти, текст «Місто не знайдено» або «Список збережених міст порожній». | Кнопка «Знайти місто» або введення запиту в рядок пошуку. | *«Результатів не знайдено. Перевірте правильність написання міста.»* |
| **5** | **Network Error (Помилка мережі без кешу)** | Фоновий градієнт спокійного неба, іконка відсутності зв'язку, картка «Немає підключення до інтернету», кнопка «Повторити». | Кнопка «Повторити спробу» (тач-таргет 48dp), перехід у налаштування або вибір міста з локальної бази. | *«Помилка мережі. Немає підключення до інтернету. Натисніть кнопку Повторити.»* |
| **6** | **Offline Cache (Свіжий офлайн-кеш)** | Повний погодний екран із кешу, під шапкою непомітний бейдж: «Офлайн-режим. Дані збережено о [Час]». | Повний перегляд усіх вкладок, перемикання збережених міст, повторна спроба оновлення. | *«Відображаються збережені дані станом на [Час]. Підключення до інтернету відсутнє.»* |
| **7** | **Stale Cache (Застарілий кеш при збої мережі)** | Повний інтерфейс із застарілими даними, попереджувальний банер янтарного кольору: «Дані застаріли ([Час оновлення]). Натисніть для оновлення». | Тап на банер для повторного запиту, перегляд прогнозу. | *«Увага: дані застаріли. Останнє оновлення о [Час]. Натисніть двічі для повторного запиту.»* |
| **8** | **API Quota Exhausted (HTTP 429)** | Відображення наявного кешу, нижнє спливаюче повідомлення (Snackbar): «Ліміт запитів вичерпано. Дані оновляться автоматично пізніше». Без зависання застосунку. | Звичайне користування наявними даними, перемикання міст з кешу. Нескінченні повторні запити блокуються. | *«Ліміт запитів до сервера тимчасово вичерпано. Використовуються збережені дані.»* |
| **9** | **GPS Permission Denied (Відмова в доступі до GPS)** | Застосунок продовжує працювати у штатному режимі з дефолтним містом. При спробі натиснути кнопку GPS з'являється діалог пояснення з кнопками «Ввести місто вручну» та «Налаштування». | Пошук будь-якого міста світу вручну без потреби в GPS, перехід у системні налаштування. | *«Доступ до геолокації відхилено. Ви можете шукати населені пункти вручну через пошук.»* |
| **10** | **Approximate Location (Приблизна геолокація)** | Відображення міста/району на основі приблизних координат (`ACCESS_COARSE_LOCATION`) без вимоги точного GPS. | Повноцінний прогноз без обмежень функцій. | *«Місцезнаходження визначено приблизно: [Назва міста].»* |
| **11** | **Missing Data (Частково відсутні метеодані)** | Якщо сервер не надав УФ-індекс або тиск, у відповідній картці відображається риска «—» замість 0 або крашу. Решта блоків працюють штатно. | Перегляд наявних показників. | *«Показник [Назва показника] тимчасово недоступний для цього регіону.»* |

## 3. Вимоги доступності та ергономіки (Accessibility & Ergonomics — A1.3)

1. **Масштабування Dynamic Type до 200%:**
   - Усі розміри тексту оголошуються виключно в одиницях `sp`.
   - Заборонено хардкодити фіксовану висоту контейнерів у `dp` для текстових блоків. Використовувати `Modifier.wrapContentHeight()`.
   - При 200% масштабуванні текст переноситься на новий рядок без обрізання та перекриття сусідніх елементів.
2. **Мінімальні тач-таргети (Touch Targets):**
   - Усі клікабельні елементи (іконки пошуку, налаштувань, стрілки, кнопки вкладок, елементи списку міст) мають інтерактивну область розміром **не менше 48 × 48 dp** (`minimumInteractiveComponentSize`).
3. **Колірний контраст (WCAG 2.1 AA):**
   - Контрастність тексту до фону градієнта складає не менше **4.5:1** для звичайного тексту та не менше **3.0:1** для великих цифр температури.
   - У темній темі забезпечується контрастність ≥ 7:1.
4. **Семантика графіків:**
   - Графіки сплайнів температури та опадів дублюються текстовими числовими мітками біля кожної ключової точки.
   - Для користувачів TalkBack графік озвучується як послідовний перелік: *«Графік температури на 14 днів: сьогодні від +11 до +21 градусів, завтра від +10 до +19...»*.
5. **Керування однією рукою (Thumb Zone):**
   - Усі ключові інтерактивні елементи, вкладки навігації та списки оптимізовані для доступу великим пальцем у нижніх 60% екрана.
6. **Підтримка Reduced Motion:**
   - При увімкненому системному параметрі «Зменшити рух»:
     - Вимикаються циклічні анімації сходу сонця на Canvas (сонце відображається статично у точці поточного часу).
     - Вимикається біжуча хвиля Shimmer (замінюється плавним статичним контуром).
     - Переходи між вкладками виконуються миттєво або через чистий Crossfade.
