## Критерії приймання (Acceptance Criteria)

1. Описано основні сценарії взаємодії: перший запуск (без примусового запиту GPS), перегляд поточної погоди, скрол 24h погодинного ряду, список 14 днів, деталі вибраного дня.
2. Спроєктовано екран пошуку міст: стан введення, підказки, результати, збереження в «Обрані», стан відсутності інтернету.
3. Описано поводження при відмові користувача в наданні геолокації (graceful degradation: пропозиція вибрати місто вручну, ніяких блокуючих діалогів).
4. Зафіксовано вимоги доступності (контраст WCAG AA, мінімальний розмір таргетів 48dp, текстові альтернативи погодних іконок для TalkBack).
5. Визначено специфікацію поведінки анімації: плавні атмосферні переходи при звичайному режимі та повне відключення/спрощення при активації системної опції «Зменшення руху» (reduced motion).
