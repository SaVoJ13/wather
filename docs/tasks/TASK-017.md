## Критерії приймання (Acceptance Criteria)

1. [x] **Преміальна дизайн-система Google Material You (Material 3):**
   - 7 динамічних погодних атмосфер (Ясне небо день/ніч, Мінлива хмарність, Суцільна хмарність, Дощ/Злива, Гроза, Сніг, Туман);
   - Повноцінні палітри для світлої та темної тем з контрастом WCAG AA (≥ 4.5:1 для тексту, ≥ 3.0:1 для великих цифр і графіків);
   - Шкала типографіки (Roboto / Google Sans, 11sp–84sp) з адаптацією до масштабування 200%;
   - Сітка відступів на базі 4dp, тач-таргети ≥ 48dp, радіуси скруглення (8dp, 12dp, 16dp, 24dp, 28dp, pill 100dp);
   - Правила системного `reduced-motion` (заміна анімацій на статичні стани).
2. [x] **Специфікація 3 основних розділів інтерфейсу:**
   - **Розділ 1: «Зараз»:** Current Weather Hero (84sp), 24h погодинна смуга від поточної години, 2x2 сітка метрик, схід/захід сонця на Canvas, динамічна атрибуція джерела;
   - **Розділ 2: «Прогноз»:** 16-денний прогноз із температурними кривими мін/макс на Canvas, стовпчиками опадів, трендами тиску й вітру, картками днів з BottomSheet деталями;
   - **Розділ 3: «Місця & Радар»:** Управління обраними містами, миттєвий пошук із фільтрацією, кнопка локації за явним кліком із контекстним діалогом, погодний радар 360° на Canvas із часовими кроками, одиниці виміру та вибір з 8 мов.
3. [x] **Повна специфікація UI-станів:**
   - Loading Shimmer (мерехтливий скелетон з fallback на статичний блок при reduced-motion);
   - Success (динамічний градієнт, Crossfade 250 мс);
   - Error з кнопкою Retry (48dp);
   - Stale / Offline Banner (при відсутності мережі або HTTP 429, показ точного часу кешування);
   - Empty Search State (зрозумілі підказки для користувача).
4. [x] **Контейнер для реклами Google AdMob:**
   - Фіксована висота 50dp у нижній частині екрана;
   - Нульовий зсув макета (Zero CLS);
   - Маркування «Реклама» / «Ad» 14dp;
   - Сувора відсутність реклами у віджетах.
5. [x] **Специфікація Jetpack Glance віджетів:**
   - Компактний 2x2 та розширений 4x2 зі скляною фаскою Glassmorphism і 4-денною таблицею;
   - Дотримання системних лімітів RemoteViews (без нескінченних анімацій, показ часу оновлення).
6. [x] **Наочні ASCII та Mermaid схеми екранів та станів.**
7. [x] **Передача результатів на незалежну перевірку QA (без самоверифікації).**
