## Критерії приймання (Acceptance Criteria)

1. [x] Спроєктовано чітку та вичерпну інформаційну архітектуру застосунку навколо трьох незалежних вкладок у нижній навігації (Bottom Navigation Bar):
   - Вкладка 1: «Зараз» (Поточна погода Hero 84sp, 24h погодинний ряд від поточної години, сітка ключових метрик 2x2, анімована Canvas-дуга сходу/заходу сонця, динамічна ліцензійна атрибуція, AdMob слот).
   - Вкладка 2: «Прогноз» (Повний 16-денний прогноз, інтерактивний сплайн-графік мін/макс температур із скраббінгом пальцем, стовпчики опадів, тренди тиску/вітру, 16 карток днів, виклик Bottom Sheet деталей дня).
   - Вкладка 3: «Місця» (Збережені міста з індикацією активного, швидке додавання, Swipe-to-Dismiss із 4с Undo, швидкий пошук онлайн/офлайн, кнопка «Моє місцезнаходження» за явним кліком).
2. [x] Окремий екран «Налаштування» (Settings Screen):
   - Винесено в окремий повноцінний екран, доступний через іконку шестерні у TopBar на всіх вкладках.
   - Містить перемикання одиниць виміру (°C/°F, км/год / м/с / mph, гПа / мм рт. ст.), селектор 8 мов (`uk`, `pl`, `en`, `de`, `es`, `it`, `ru`, `default`), юридичну інформацію та Open Source ліцензії.
3. [x] Виключення LIVE-радара з MVP:
   - Процедурну імітацію радара («псевдорадар») виключено з MVP через відсутність валідного відкритого джерела радарних тайлів або супутникових знімків для уникнення дезінформації користувачів (No Fake Data).
   - Функціонал реального радіолокатора перенесено в беклог Post-MVP.
4. [x] Ергономіка однієї руки (One-Handed Usability / Thumb Zone):
   - Розташування ключових контролів у нижніх 60% екрана (Natural Thumb Zone).
   - Доступ до головних функцій у 1–2 тапи.
   - Використання висувних Bottom Sheets для перегляду деталей замість переходу на нові екрани.
5. [x] Детально описано й адаптовано повні користувацькі сценарії (User Flows 1–9) під 3-вкладкову модель:
   - Flow 1: Перший запуск (Zero intrusive permissions, дефолтне місто за регіоном, системна мова).
   - Flow 2: Пошук населених пунктів у Вкладці «Місця», швидке додавання та видалення з 4с Undo.
   - Flow 3: Одноразовий GPS за явною дією (Rationale Dialog, Coarse/Fine, м'яка обробка відмови, Zero Background Location).
   - Flow 4: Взаємодія з графіками на 16 днів, скраббінг пальцем із тултіпом та Bottom Sheet деталей.
   - Flow 5: Астрономічний цикл та сонячна дуга (Daylight & Solar Cycle Inspection на Canvas).
   - Flow 6: Екран налаштувань через TopBar шестерню: одиниці виміру та вибір з 8 мов.
   - Flow 7: Життєвий цикл та поведінка віджетів 2x2 та 4x2 (Glassmorphism, нуль реклами, автооновлення через AlarmManager).
   - Flow 8: Офлайн-робота, повернення мережі та обробка HTTP 429 (Too Many Requests).
   - Flow 9: Слот банера Google AdMob у нижній частині (Zero CLS, фіксована висота, заборона реклами у віджетах).
6. [x] Зафіксовано критерії доступності WCAG 2.1 AA:
   - Контрастність тексту ≥ 4.5:1 (для великих чисел ≥ 3.0:1).
   - Мінімальні тач-таргети ≥ 48x48dp із відступами ≥ 8dp.
   - Семантичні підписи TalkBack рідною мовою для всіх елементів.
   - Dynamic Type масштабування до 200%.
   - Поведінка системного режиму Reduced Motion.
7. [x] Дотримано політику $0 додаткового бюджету (Zero Budget Policy) та збережено непорушність доменних/API контрактів.
8. [x] Повністю синхронізовано `docs/ux/UX_SPEC.md` (v2.1) та `docs/ux/USER_FLOWS.md` (v2.1).
