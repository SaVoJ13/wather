## Критерії приймання (Acceptance Criteria)

1. [x] Прибирання повідомлення GPS при запуску:
   - у `WeatherMainScreen.kt` видалено спливаючий Snackbar `"Визначаємо населений пункт за GPS..."`, визначення та відновлення збереженої локації відбуваються плавно і непомітно для користувача.
2. [x] Блок «Схід і захід сонця» (`SunriseSunsetCard.kt`):
   - відображає точний час сходу (`sunrise`) та заходу (`sunset`) для поточної доби;
   - тривалість світлового дня та час до настання сходу/заходу;
   - виразна анімація небесної дуги (Compose Canvas): плавна дуга горизонту, золотистий градієнт прогресу світлового дня, анімоване сяюче сонце на відповідній позиції дуги за поточним часом;
   - підтримка режиму `reduced-motion`.
3. [x] Блок «Погодний радар» (`WeatherRadarCard.kt`):
   - розміщено в нижній частині головного екрана перед/після блоку щоденного прогнозу;
   - стилізована мапа опадів та хмарності навколо координат користувача (радіус 50 км);
   - плавна анімація обертання сканувального променя радара (radar sweep line) та анімовані кластери опадів;
   - інтерактивні часові кроки (-30 хв, Зараз, +30 хв, +60 хв) з кнопкою відтворення Play/Pause;
   - шкала інтенсивності опадів (Мряка -> Дощ -> Злива -> Гроза).
4. [x] Кешування:
   - `WeatherLocalCache.kt` серіалізує та відновлює `sunrise` і `sunset` у дисковому кеші.
5. [x] Тестування:
   - нові unit-тести для розрахунку прогресу сонця та форматування часу;
   - `./gradlew testDebugUnitTest` завершується успішно без помилок (51/51 тестів пройдено).
6. [x] Незалежна верифікація QA:
   - статус `QA_VERIFIED` від агента `qa-privacy` згідно з п. 2.1 Конституції.
