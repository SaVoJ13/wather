## Критерії приймання (Acceptance Criteria)

1. Проведено незалежний аудит `AndroidManifest.xml` на предмет мінімальності дозволів:
   - підтверджено відсутність `ACCESS_BACKGROUND_LOCATION`;
   - підтверджено відсутність аналітичних та рекламних SDK;
   - перевірено правила мережевої безпеки (Network Security Config).
2. Перевірено поводження застосунку у сценаріях з геолокацією:
   - дозвіл надано (Precise / Coarse);
   - у дозволі відмовлено (Never ask again або Deny);
   - пошук міста функціонує на 100% при повністю вимкненому GPS.
3. Перевірено сценарій роботи в режимі літака / відсутності мережі:
   - застосунок не падає;
   - відображаються збережені закешовані дані з індикатором застарілості;
   - кнопка повтору запиту коректно реагує на відновлення з'єднання.
4. Перевірено режим «Зменшення руху» (reduced-motion): важкі анімації вимкнено або замінено на статичні.
5. Зафіксовано статус `QA Verified` для кожної завершеної задачі на основі фактичних доказів.
