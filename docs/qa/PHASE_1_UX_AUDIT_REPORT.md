### 2.2. Доступність за стандартом WCAG 2.1 AA
- **Вимога:** Мінімальні тач-таргети ≥ 48x48dp, контрастність кольорів (≥ 4.5:1 для тексту, ≥ 3.0:1 для великих цифр і графіки), TalkBack семантика рідною мовою, масштабування шрифту до 200%.
- **Фактичні докази:**
  - **Тач-таргети:** DESIGN_SYSTEM.md (п. 4.3) та USER_FLOWS.md (розділ 5) суворо фіксують: усі клікабельні зони (кнопки дій, іконки TopBar, елементи списків міст, дні прогнозу, чіпи) мають розмір не менше **48x48dp** із застосуванням Modifier.sizeIn(minWidth = 48.dp, minHeight = 48.dp) та відступами між сусідніми таргетами ≥ 8dp.
  - **Контрастність кольорів:** DESIGN_SYSTEM.md (п. 2.1, 2.2) містить матрицю контрастності для всіх 7 атмосфер неба. У денних палітрах контраст становить **4.5:1 – 8.4:1** (рівень AA/AAA), у нічних палітрах — **8.9:1 – 12.2:1** (рівень AAA). Для попереджувальних плашок застарілих даних (status.warning.stale-text) забезпечено контраст **≥ 7:1**.
  - **TalkBack:** UI_SPECIFICATION.md (п. 3.1) та USER_FLOWS.md (розділ 5) регламентують повне словесне озвучення рідною мовою для всіх нетекстових елементів (іконки погоди, графіки, статус свіжості даних, результат пошуку).
  - **Dynamic Type (до 200%):** DESIGN_SYSTEM.md (п. 3) та USER_FLOWS.md (розділ 5) забороняють фіксовані dp-висоти для текстових карток; усі розміри вказані в sp з wrapContentHeight() та безпечним скороченням TextOverflow.Ellipsis.
- **Статус:** **ВИКОНАНО (PASS)**.

### 2.3. Системний режим зменшення руху (Reduced Motion)
- **Вимога:** Вимкнення обертання радара, сонячної анімації, заміна Shimmer на статичні блоки.
- **Фактичні докази:**
  - DESIGN_SYSTEM.md (розділ 5) та USER_FLOWS.md (розділ 5) визначають реакцію на системне налаштування Settings.Global.ANIMATOR_DURATION_SCALE == 0:
    - **Погодний радар:** 360° sweep-промінь зупиняється (фіксується на куті 45° або замінюється статичними колами), виключаючи безперервний рух.
    - **Схід / Захід сонця:** Сонце малюється одразу в поточній позиції на дузі без 1200 мс анімації сходження.
    - **Skeleton Loading:** Замість горизонтальної хвилі Shimmer відображається статичний напівпрозорий блок без мерехтіння.
    - **Графіки та переходи:** Графіки кресляться миттєво без проростання ліній; переходи між екранами виконуються за ≤ 100 мс без зміщень.
- **Статус:** **ВИКОНАНО (PASS)**.

### 2.4. Повнота станів інтерфейсу (UI States FSM)
- **Вимога:** Loading, Success, Error з Retry, Stale/Offline банер при відсутності мережі або HTTP 429.
- **Фактичні докази:**
  - UI_SPECIFICATION.md (розділ 3) містить формальну кінцеву машину станів (Mermaid FSM diagram) та детальну таблицю поведінки:
    - **Loading:** Shimmer-скелетони для Hero, погодинної стрічки та сітки метрик.
    - **Success:** Динамічний градієнт атмосфери, Crossfade 250 мс, повний набір віджетів.
    - **Error (без кешу):** Центрована ілюстрація, чіткий текст помилки та велика кнопка «Спробувати знову» (48dp).
    - **Stale / Offline (з кешем):** Повноцінний інтерфейс закешованого прогнозу з верхнім бурштиновим бейджем CloudOff *«Офлайн-режим. Дані від [Час]»* та кнопкою ручного оновлення.
    - **HTTP 429 (Too Many Requests):** М'яке сповіщення через SnackBar без блокування перегляду, використання останнього надійного кешу та експоненційне сповільнення повторних запитів (Backoff).
    - **Empty Search:** Дружня підказка при відсутності результатів пошуку.
- **Статус:** **ВИКОНАНО (PASS)**.
