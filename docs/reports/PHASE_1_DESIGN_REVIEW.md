## 3. Специфікація Google AdMob Anchored Adaptive Banner (Zero CLS)

Для забезпечення нульового зсуву макета (Cumulative Layout Shift, CLS = 0) та відповідності правилам Google AdMob:
1. **Динамічний розрахунок розміру:**
   Використовується офіційний виклик Google Mobile Ads SDK:
   ```kotlin
   val adSize = AdSize.getCurrentOrientationAnchoredAdaptiveBannerAdSize(context, screenWidthDp)
   val bannerHeightDp = adSize.getHeightInPixels(context) / density
   ```
2. **Резервування контейнера (Zero CLS):**
   У Jetpack Compose контейнер банера резервує розраховану висоту `bannerHeightDp` (зазвичай 50–90dp) одразу при композиції екрана через `Box(modifier = Modifier.fillMaxWidth().height(bannerHeightDp.dp))` із Shimmer-скелетоном або прозорим фоном. Контент екрана ніколи не стрибає при завантаженні чи невдачі показу реклами.
3. **Маркування:**
   Контейнер має чітку позначку «Реклама» / «Ad» (14dp).
4. **Сувора заборона реклами у віджетах:**
   Віджети Glance використовують виключно системні ресурси Android і ніколи не містять реклами.

## 4. Доступність (Accessibility) та Dynamic Type

1. **Тач-таргети:** Кожен клікабельний елемент (іконка пошуку, шестерня налаштувань, вкладка навігації, кнопка GPS) має розмір **≥ 48x48dp** із відступами між сусідніми елементами ≥ 8dp.
2. **Контрастність (WCAG 2.1 AA):**
   - Звичайний текст на всіх 7 погодних градієнтах: **≥ 4.5:1** (денні теми 4.5:1–8.4:1; нічні теми 8.9:1–12.2:1).
   - Великі цифри температури (84sp bold): **≥ 3.0:1** (фактично ≥ 4.5:1).
   - Бейдж офлайн-даних: контраст **≥ 7.0:1**.
3. **Dynamic Type (Масштабування до 200%):**
   - Усі розміри шрифтів задані в `sp`.
   - Текстові контейнери використовують `wrapContentHeight()` без жорстко зафіксованої висоти.
   - Елементи сітки підтримують автоматичне перенесення рядків (FlowRow / Flexible layout), щоб уникнути обрізання тексту при максимальному збільшенні шрифту в системі.
4. **Reduced Motion:**
   - Повна підтримка системної настройки зменшення руху (`ANIMATOR_DURATION_SCALE == 0`): анімації сонця та плавні переходи вимикаються, Shimmer-ефекти замінюються на статичні напівпрозорі блоки.
