# База уроків та виявлених пасток / LESSONS

## 1. Середовище розробки Windows та інструменти

- **Урок [2026-11-17]:** Запуск PowerShell-команд вимагає валідної робочої директорії. Якщо процес стартує у директорії, яка була видалена або не створена, PowerShell падає з помилкою «no such directory».
  - *Правило:* Завжди перевіряти наявність папки перед виконанням або створювати каталог заздалегідь.
- **Урок [2026-11-17]:** Системні змінні `java` та `gradle` не додані автоматично до глобального системного `PATH` у Windows. Проте Android Studio та JBR (OpenJDK 25) встановлені у `C:\Program Files\Android\Android Studio\jbr`, а Android SDK — у `C:\Users\cocro\AppData\Local\Android\Sdk`.
  - *Правило:* Під час компіляції та тестів явно використовувати `JAVA_HOME="C:\Program Files\Android\Android Studio\jbr"` або прямий шлях до `bin/java.exe`.

## 2. Погода та мережеві контракти (Open-Meteo)

- **Урок [2026-11-17]:** Безкоштовний Open-Meteo має суворі некомерційні умови ліцензування CC BY 4.0.
  - *Правило:* Ніколи не прив'язувати внутрішню бізнес-логіку UI до сирих DTO Open-Meteo. Використовувати чистий Domain Interface (`WeatherRepository`), щоб у разі зміни постачальника (наприклад, переходу на інший API для комерційного релізу) змінити лише один клас адаптера.
- **Урок [2026-11-17]:** Відповіді погодного API містять часові пояси локації (`timezone`, наприклад `Europe/Kyiv`).
  - *Правило:* Час погодинного прогнозу повинен відображатися з урахуванням локального часу досліджуваного міста, а не лише системного часу телефона користувача (особливо при перегляді погоди в інших часових поясах).

## 3. Віджети Android (Jetpack Glance)

- **Урок [2026-11-17]:** Віджети Android працюють через механізм RemoteViews і мають жорсткі ліміти пам'яті та частоти оновлень. Покадрова нескінченна анімація (Lottie, Canvas loops) у віджеті виснажує акумулятор і блокується системою.
  - *Правило:* У віджеті застосовувати статичні естетичні ілюстрації з переходом стану при плановому оновленні. Повноцінну анімацію неба розміщувати лише всередині головного застосунку.

---

## 4. Приватність та дозволи Android

- **Урок [2026-11-17]:** Запит локації безпосередньо під час запуску застосунку викликає недовіру та призводить до високого відсотка відмов. Крім того, Google Play дуже суворо оцінює використання локації.
  - *Правило:* Запитувати дозвіл лише після кліку на «Моє розташування». Застосунок повинен повноцінно працювати взагалі без дозволів GPS — виключно через текстовий пошук міст.

## 5. Формування та інтерполяція рядків у кодогенерації (Фідбек Власника)

- **Урок [2026-11-17]:** При автогенерації чи модифікації Kotlin-файлів через скрипти знаки інтерполяції `"$variable"` можуть розгортатися оболонкою у порожні рядки, якщо рядок не екрановано. В результаті в UI залишалися символи без значень (наприклад: `+°`, ` гПа`, ` км/год`, ` мм`).
  - *Правило:* Обов'язкова перевірка фактичного тексту створених Compose-компонентів на коректну інтерполяцію чисел і значень перед складанням звіту.
- **Урок [2026-11-17]:** Наявність репозиторію та адаптерів без прямого підключення до реального HTTP-транспорту залишає UI на статичних фікстурах. Користувач очікує інтерактивного вибору міста та реальних даних з мережі.
  - *Правило:* Забезпечувати безперебійний зв'язок: реальний HTTP-клієнт за наявності інтернету та прозорий мок/кеш-фолбек за його відсутності, а також повноцінне діалогове вікно пошуку з автодоповненням.

## 6. Тестування Android на JVM та динамічні проксі

- **Урок [2026-11-22]:** У локальних unit-тестах Android на десктопній JVM класи з `android.jar` (зокрема `org.json.JSONObject` та `JSONArray`) за замовчуванням мають заглушки, які викидають `RuntimeException: Method ... not mocked`.
  - *Правило:* Для чистих unit-тестів серіалізації/кешу без запуску важкого емулятора або Robolectric слід підключати `testImplementation("org.json:json:20240303")`. Ця бібліотека працює суто під час компіляції тестів і має нульовий розмір (0 байт) у релізному APK.
- **Урок [2026-11-22]:** У динамічних проксі (`java.lang.reflect.Proxy`) для `SharedPreferences.Editor` метод `apply()` у Java має тип повернення `void`. Якщо `InvocationHandler` повертає для нього `true` (Boolean), Java Reflection викидає `IllegalArgumentException`.
  - *Правило:* Для методів з типом `void` обробник проксі повинен завжди повертати `null`.
- **Урок [2026-11-23]:** У Material 3 компонент `NavigationBar` із ненульовим `tonalElevation` (наприклад, `8.dp`) та напівпрозорим білим `containerColor` (`surfaceTint` 8–20% білого) створює дуже світлу підкладку, на якій світлі іконки й текст стають нечитабельними. Крім того, стандартний `labelSmall` (`11.sp`, `letterSpacing = 0.5.sp`) обрізає довгий український підпис «Прогноз на 14 днів» у вузькій третині екрана.
  - *Правило:* Для нижньої панелі навігації поверх динамічних погодних градієнтів використовувати непрозорий/високощільний темний графітово-синій контейнер (`0xF50F172A`) із `tonalElevation = 0.dp`, явними кольорами `NavigationBarItemDefaults.colors()` (WCAG AA >= 4.5:1 для тексту та >= 3:1 для іконок) і компактним `letterSpacing = 0.sp`, `fontSize = 10.5.sp`, `maxLines = 1`.
